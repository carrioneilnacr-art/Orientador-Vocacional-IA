# Recursos independientes de Plaza de Lima

Estos recursos se generan como objetos individuales transparentes. No contienen una captura de la referencia ni personajes protagonistas incrustados. Su posición, profundidad y colisiones se definen en `PlazaScene.tsx`.

Generados mediante la herramienta integrada ImageGen y normalizados para el juego:

- `catedral.png`: fachada colonial con torres, reloj y puertas, fuente `exec-7f2bbe8b-f8ee-4360-b6bc-01f32eefb2b0.png`.
- `fuente.png`: fuente de dos niveles con base de piedra, fuente `exec-c54ef05c-912e-4fba-88ac-ecfee060b6de.png`.
- `galeria.png`: edificio colonial ocre con balcones de madera y arquería, fuente `exec-26a6eedd-b73d-4c74-b846-37b645d21eaa.png`.
- `palmera.png`: palmera completa con tronco y hojas, fuente `exec-365499ac-beb0-4ea6-be3a-e6800f0178ff.png`.
- `jardin.png`: jardinera de piedra con flores, fuente `exec-3ad8010f-195e-440c-b768-1bbab07cbf23.png`.

Prompt común de producción: “Single independent environment sprite for a layered 2D Lima plaza game. The user-provided Plaza de Lima image is a style guide only, not an edit target. Premium richly detailed hand-painted pixel art, crisp pixel clusters, warm daylight. Isolated centered object on truly transparent background. No ground plane, no sky, no people, no Chaski, no letters, no text, no collage.” Se añadió la descripción individual de cada objeto indicada arriba.

Los faroles, bancas, puesto, rejas, gradas y mirador son piezas SVG independientes del proyecto. Los objetos individuales se ordenan por su coordenada de apoyo sobre el suelo, igual que Chaski y los NPC.
