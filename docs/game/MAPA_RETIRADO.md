# Mapa retirado para reconstrucción

La plaza activa y sus renderizadores se retiraron a petición del usuario. La pantalla conserva el marco del juego y muestra el espacio vacío. Las imágenes, los datos de referencia, los diálogos y el progreso guardado se conservaron para reutilizarlos.

Respaldo completo anterior a la retirada:
`D:/Chaski-backups/plaza-lima-respaldo-completo-20261031-2104.zip`

Contiene 270 archivos de código, datos, imágenes y documentación, con un manifiesto SHA256 verificado. El ZIP mantiene las rutas relativas del proyecto.

Las imágenes conservadas están en `public/game/`, incluidos los siete recursos nuevos de `public/game/plaza-lima/fiel/`. La generación pendiente se detuvo.
